# Jach’a Puno — portal para aliados

Portal estático en español, con Urbanist alojada localmente y la paleta editorial de los cinco segmentos. Se conserva el proyecto `appgprj_6addc8ca660081919453f1f4cc331fd3` y el acceso exclusivo del propietario.

- Cinco módulos: S/ 250 por módulo, incluida la franja horizontal.

## Desarrollo y validación

Sin dependencias ni compilación. `dist/` contiene el sitio y sus recursos. `node --check dist/app.js` valida sintaxis. Fuente Urbanist y licencia SIL Open Font License incluidas en `dist/assets/`.

Navegación por anclas, cinco pestañas editoriales, filtros de muestra, visor con ampliación y teclado, selector de seis opciones publicitarias, aporte institucional y preparación de consultas. No se modifican las políticas de acceso.
